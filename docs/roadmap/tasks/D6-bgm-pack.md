# D6 — BGM 소스 팩 (절차 생성 음악, 저작권 0)

- **이슈**: 신규 (마케팅 3요소 중 '음악'의 소재 — B7 BGM 트랙의 선행)
- **의존**: 없음

## 목표

broll 팩과 같은 철학의 **절차 생성 음악 6무드** — 시드 고정 순수 PCM 신스(외부 샘플/저작권 0, 오프라인, 결정적) → `assets/bgm/*.m4a` + LLM 선택용 catalog.json. 루프 클린(꼬리를 머리로 접어 이음새 없음).

## 왜

마케팅 영상 "완성품 느낌" 3요소(전환✓·음악·브랜딩) 중 음악의 소재가 전무. 업계(Topview/ChatCut)는 생성 음악이 기본. 우리는 로컬 팩(기본) + 추후 BYOK 생성 어댑터(D4 계열).

## 완료 조건 (AC)

- [ ] `scripts/make-bgm-pack.ts` — 시드 고정, 신스 프리미티브(osc/ADSR/원폴 LP/핑퐁 딜레이/소프트 리미터), 무드별 진행·보이싱
- [ ] 루프 클린: 렌더 꼬리(2s)를 머리에 접어 이음새 제거, 길이 = 마디 정수배(~24s)
- [ ] `assets/bgm/<id>.m4a`(AAC 192k — 동봉 LGPL ffmpeg에 lame 없음, Electron AAC 재생 가능) + `catalog.json`(id/설명/bpm/durationSec/loopable)
- [ ] 통합 테스트: probe(오디오·길이), 피크 통계(무음 아님·클리핑 아님), 카탈로그 정합
- [ ] 검증 체인 그린 + 샘플 청취용 전달(사람 귀 검수는 사용자)

## 설계 가이드

- 음질 수칙: 패드=디튠 2-3 osc(soft saw/tri)+느린 어택+LP, 플럭=exp 디케이+딜레이 센드, 베이스=사인+옥타브 위 살짝, 킥=피치 드랍 사인, 햇=화이트노이즈 30ms+HP성 셰이핑. 마스터 = 피크 -1.2dBFS 노멀라이즈 + 소프트 리미터.
- app 노출은 B7(BGM 트랙)에서 — 이번엔 소재+카탈로그만.
