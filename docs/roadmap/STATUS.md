# 로드맵 상태 원장 (단일 진실원천: 진행)

> **갱신 규칙 (모든 에이전트 필수)**
> 1. **착수 시**: 아래 체크포인트에 작업 ID·다음 액션 기록, 원장에서 상태 `doing`.
> 2. **진행 중**: 의미 있는 지점(설계 결정, 파일 완성, 막힘)마다 **작업 패킷의 '진행 저널'에 append**. 체크포인트의 '다음 액션'을 항상 최신으로 — **compact/세션 종료가 언제 와도 이 두 곳만 최신이면 안전**하다.
> 3. **완료 시**: 검증 그린 → 커밋 → 원장 `done`+커밋 해시 → 체크포인트를 다음 작업으로 갱신.
> 4. 체크포인트는 **덮어쓰기**(항상 현재만), 패킷 저널은 **append-only**(역사).

---

## ⚡ 체크포인트 (덮어쓰기 — 새 세션은 여기부터)

```yaml
진행중_작업: 없음
다음_작업: B2            # 패킷: 착수 시 _TEMPLATE로 생성 (썸네일 필름스트립 + 파형)
다음_액션: B2 착수 — 프록시에서 ffmpeg 배치 썸네일/파형 추출 + 디스크 캐시 설계부터
막힌_것: 없음
마지막_갱신: 2026-07-10 (B1 완료, v0.1.11)
비고: 사용자 결정(2026-07-10) — "엔진·에디터 고도화부터"(B-트랙 우선). 이후 B4/B5(전환·배속) → A-트랙 복귀. 플러그인화는 A6(ChatCut 패턴 = git 리포, 승인 불필요).
```
