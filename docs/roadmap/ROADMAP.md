# dawn-cut 운영 로드맵 (단일 진실원천: 계획)

> **전략적 근거·경쟁 분석은 [`docs/VIBE-EDITING-ROADMAP.md`](../VIBE-EDITING-ROADMAP.md)** (Palmier Pro/CapCut 갭 분석, 2026-07).
> **진행 상태는 이 파일이 아니라 [`STATUS.md`](./STATUS.md)에서 관리한다** — 이 파일은 "무엇을 왜"만, STATUS는 "어디까지"만.
> 작업 단위 상세(목표/AC/설계/저널)는 [`tasks/<ID>-*.md`](./tasks/) 패킷. **패킷은 착수 시점에 [`tasks/_TEMPLATE.md`](./tasks/_TEMPLATE.md)로 생성**한다(Phase A는 미리 작성됨).

## 규칙

- 작업 ID는 불변(`A1`, `B3` …). 완료돼도 ID는 재사용하지 않는다. 새 작업은 해당 Phase 끝 번호로 추가.
- 순서는 권고일 뿐 강제 아님 — 의존성(`dep`)만 지키면 됨.
- 한 작업 = 한 사이클(검증 그린 + 커밋 + STATUS 갱신)로 끝나는 크기. 크면 쪼개서 `A4a/A4b`처럼 파생.
